# SBXR documentation

Start with the [repository README](../README.md) for the supported product
journey. For implementation work, use the [agent code map](agents/code-map.md)
to find the owning module and focused tests; [CONTEXT.md](../CONTEXT.md) defines
the shared terms.

The current release-qualification procedure is [MVP live acceptance](acceptance/mvp-live-acceptance.md).
It defines the five `mvp-live-v1` journeys and the manual observation handoff.
[ADR-0023](adr/0023-mvp-live-acceptance.md) records that scope decision.

[Acceptance](acceptance/README.md) separates the current procedure from dated
reports and the historical V4 material. [Research](research/README.md) contains
source reviews and investigation notes; it does not establish current product or
release state. ADRs record decisions in effect for their named scope.
