# Installation preflight and SSH safety

SBXR admits only a proven Clean VPS or current Managed installation through staged, revision-bound preflight; owns one nftables table without fighting another firewall manager; treats the approved profile ports as defaults with safe random alternatives for occupied configurable ports; preserves the detected SSH port through atomic firewall application and automatic rollback without requiring a second SSH connection; keeps provider-firewall correction manual; and mutates only Cloudflare resources proven by immutable IDs under the minimum persisted account-and-zone authority. These choices favor bounded automatic rollback and exact Correction Flows over unsafe adoption, provider-specific credentials, indefinite retries, or bypass controls; the canonical decision is [Define installation preflight and SSH safety](https://github.com/albertloky/SBXR/issues/12#issuecomment-5187474911).
