# Establish the V3 proxy product and Modules

V3 is a new SBXR product line for one Owner and one Ubuntu Server 24.04 `amd64` host. It is not a migration from V1 or V2. Proxy Installation is the deep Module that owns the installed proxy journey: Proxy Installation Status, legal actions, setup, incomplete-action completion, Client Configuration disclosure, local inspection, Complete removal orchestration, Ownership Record rules, durable checkpoints, interruption direction, progress, and typed results. Software Lifecycle remains a separate Module and retains installed-software status, Installed Record and executable authority, Release Identity, qualified stable discovery, update, rollback, forward completion, recovery, and exact-executable restoration during unfinished Complete removal.

The standard-library numbered line menu is presentation. It calls Proxy Installation directly and does not coordinate Software Lifecycle or add an umbrella Journey Module. Proxy Installation exposes exactly `Review(context.Context, Action) Review` and `Execute(context.Context, PreparedAction, Confirmation, ProgressReporter) Result`. Its Action vocabulary is Status, View details, Start setup, Finish cleanup, Finish setup, Show client configuration, Complete removal, and Finish removal. `Review` always performs fresh inspection and, for a selected action, required read-only preflight. A legal review may return one opaque, memory-only, single-use Prepared Action. `Execute` consumes it once and revalidates every required fact before host mutation or credential disclosure; stale, reused, invalid, mismatched, or changed-fact authority refuses without either.

One private Host Adapter owns Ubuntu filesystem, APT, systemd, identity, process, listener, and network observations and mechanics. One private sing-box Adapter owns official key handling, server and client configuration encoding, packaged validation, and conversion of raw output to secret-safe typed facts. Each Adapter seam permits production and test Adapters, but neither becomes a public Owner Interface.

Proxy Installation owns the fixed V3 paths and values, destination order, Proxy Package Identity, ownership policy, phase and removal order, statuses, legal actions, disclosure rules, and stable result messages and codes. The Ownership Record is the only durable proxy authority; no second stored Proxy Installation Status or generic recovery record exists. `Not set up` means SBXR remains installed and no Ownership Record or V3 proxy resource exists. `Not installed` means the executable, Installed Record, Ownership Record, and all proved V3-owned proxy resources are absent.

Release Qualification remains the only stable-publication gate. V3 Packaged Live Qualification is a required stage for the first V3 release, and the Acceptance Record remains the single public secret-safe evidence authority. Automated source checks do not prove the packaged VPS, outside-client, or Owner journey.

This decision supersedes ADR-0014 only where it defines SBXR solely as an Installer-Updater, names Software Lifecycle as the sole deep Module, treats the executable and Installed Record as the complete product footprint, treats the four-operation Software Lifecycle Interface as the complete Owner product Interface, and names a complete current ADR set. It also supersedes only ADR-0001's statement that Software Lifecycle is the only product Module. It preserves ADR-0014's root-only execution, Release Identity, Release Sequence, Installed Record, qualified release delivery, Pasteable Install Command, immutable public assets, legacy refusal, and historical archive decisions. ADR-0001's stack and dependency decisions and ADR-0008 remain current authority. V3 adds no migration, automatic update design, provider automation, extra Proxy Profile or Client Identity, Owner-supplied proxy values, graphical client, subscription, QR code, UDP proof, or device-wide routing.
