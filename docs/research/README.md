# Research notes

This directory contains source reviews, design investigations, and codebase
catalogs. These notes inform implementation and documentation work, but they do
not change product behavior, acceptance policy, or a release result.

For the current MVP scope, begin with
[2026-09-12-mvp-qualification-review.md](2026-09-12-mvp-qualification-review.md)
as background, then use [ADR-0023](../adr/0023-mvp-live-acceptance.md) and the
[MVP live procedure](../acceptance/mvp-live-acceptance.md) as the current
authority. [2026-09-12-module-function-catalog.md](2026-09-12-module-function-catalog.md)
is a navigation snapshot and may become stale as files move.

[The codebase cleanup report](2026-09-12-codebase-cleanup.md) records what was
removed after adopting the MVP scope, what was retained, and the validation.

The numbered notes preserve the questions and sources of their original work.
Read their dates and stated scope before relying on an observation or
recommendation.
