# Work specifications

These records describe scoped project work: requirements, plans, tasks, findings,
and observed checks. They are not a complete log of Codex threads or conversation
transcripts. Start with the [documentation index](../docs/README.md) for current
project guidance; dated work records do not supersede it.

| Work | Scope and entry points |
|---|---|
| [001 — Project review](001-project-review/spec.md) | Existing capability review and subsequent qualification-related repairs. [Tasks](001-project-review/tasks.md) record progress; [review](001-project-review/review.md) records revision-specific evidence and limitations. |
| [002 — Project cleanup](002-project-cleanup/spec.md) | Repository maintenance inventory, navigation cleanup and equivalent encoder/digest simplification. [Tasks](002-project-cleanup/tasks.md) and [assessment](002-project-cleanup/assessment.md) distinguish delivered changes from preserved/deferred areas. |

Each feature owns its records. Do not treat another feature's unchecked task as
permission to execute its operational work. Local Spec Kit integration may be
untracked; the committed records remain readable without installing it.
